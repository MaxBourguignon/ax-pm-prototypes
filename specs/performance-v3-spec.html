1. Context

Performance V3 gives marketing managers (the core ICP) a rich page to analyze campaign performance across channels — Email, SMS, WhatsApp, Wallet — covering engagement stats (opens, clicks…) and, critically, ROI: the impact on sales after a campaign is sent. Today they have only the V2 page, which is too bare: it surfaces a single revenue-conversion KPI with little transparency on how it's computed and lacks the deeper KPIs and analysis managers need. Their workaround is exporting to spreadsheets or relying on ESP-native stats and flying blind on true cross-channel ROI. We're building it now because users need stronger ROI features to understand — and justify — the value proposition of the CRM.

Struggle magnitude: Weekly to several times/week · high — managers fly blind on ROI and can't defend CRM spend at budget reviews.

2. Goals

  1. From any campaign, the manager sees its conversion into revenue (attributed revenue, €) — per campaign and overall.
  2. The manager can configure how a conversion is calculated — choosing the trigger and the time range — within a bounded set of options (not free-form), so the page stays scalable. (Admin-only.)
  3. The manager can view detailed engagement stats (opens, clicks, …) per campaign and per channel to understand performance and adapt strategy.
  4. The page provides a complete per-campaign detail view (in-page drawer).

Not in scope

  • Per-recipient / individual-contact conversion list (this is an aggregated page).
  • Actioning from the page beyond logging — no editing/duplicating/sending of existing campaigns (read & analysis only in V3).
  • Fully free-form attribution config — only bounded trigger/range options.
